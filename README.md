# Explanation
This is a hakathon project made by Martin's team. It is essentially a machine learning model which takes player data from steam.com and predicts the number of players after some years. It then displays the data in a graph using a server on a webpage.
# Installation
```
python3 -m venv venv
. venv/bin/activate
pip install requirements.txt
```
# Running
```
python3 -m flask --app server run
```
